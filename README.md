# 技能树式平面视觉设计作品集快速模板

这是一个可以直接打开的作品集网站模板，适合设计学生用于应聘和个人品牌展示。首页是一棵技能树，每个圆点节点都可以跳转到对应作品详情页。

## 怎么改成你的作品集

1. 打开 `index.html`，把“你的名字”、个人简介、邮箱和社交平台链接替换成你的真实信息。
2. 在首页技能树里修改节点名称，比如“品牌识别”“海报版式”“包装视觉”等。
3. 在 `projects` 文件夹里修改每个作品详情页的项目名称、说明、你的角色、工具和产出。
4. 如果你有作品图片，可以把图片放到 `portfolio-template` 文件夹里，再把 `.work-visual` 那些占位区域改成 `<img src="../你的图片.jpg" alt="项目名称">`。
5. 打开 `styles.css`，可以修改 `:root` 里的颜色变量，让模板更接近你的个人风格。

## 建议准备的作品内容

- 每个项目 3 到 6 张关键图片。
- 一段 80 到 150 字的项目说明。
- 你的角色：视觉设计、品牌设计、版式设计、包装设计等。
- 使用工具：Illustrator、Photoshop、InDesign、Figma 等。

## 推荐项目顺序

1. 最完整、最能代表你的品牌或视觉系统项目。
2. 版式感强、第一眼有冲击力的海报或活动视觉。
3. 有落地感的包装、画册或社交媒体延展。
4. 字体、图形、实验类项目放在后面补充个性。

## 免费公开发布：GitHub Pages

适合你的优先级：免费、公开访问、长期维护。

1. 注册或登录 GitHub。
2. 新建一个公开仓库。如果想用个人主页形式，仓库名写成 `你的GitHub用户名.github.io`。
3. 上传本文件夹里的所有文件和 `projects` 文件夹。
4. 进入仓库的 Settings，再进入 Pages。
5. Source 选择 `Deploy from a branch`。
6. Branch 选择 `main`，Folder 选择 `/root`，保存。
7. 等待 1 到 3 分钟后，会生成公开链接。

如果仓库名是 `你的GitHub用户名.github.io`，链接通常是：

`https://你的GitHub用户名.github.io`

如果仓库名是普通项目名，比如 `portfolio`，链接通常是：

`https://你的GitHub用户名.github.io/portfolio/`
